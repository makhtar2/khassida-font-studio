# 🖋️ Khassida Font Studio — Khattul Khadim Typography

> **Projet de Recherche & Création de Polices Typographiques Numériques (.OTF / .TTF / .WOFF2 / SVG) inspirées des Manuscrits et Calligraphies des Khassaïdes de Cheikh Ahmadou Bamba (Khattul Khadim / Maghribi-Sahélien).**

---

## 📜 1. Présentation du Projet
Ce projet indépendant est dédié à la numérisation, à la vectorisation et à la génération de polices typographiques authentiques à partir des écrits manuscrits originaux de la tradition mouride (*Khattul Khadim, Kër Qasida yi, Serigne Dame Abdou Rahmane Fall, etc.*).

### Fonctionnalités du Studio :
* **Reconstitution Haute Fidélité :** Rendu du calame noir biseauté, du parchemin et des médaillons dorés traditionnels.
* **Extraction Vectorielle (SVG) :** Extraction lettre par lettre des 28 glyphes arabes avec leurs ligatures caractéristiques.
* **Générateur OpenType :** Préparation des tables de ligatures (*Kashida, Harakat, Tashkeel*) pour l'exportation vers FontForge / Glyphs App.
* **Module d'Importation :** Permet d'importer des scans et images de manuscrits pour extraire les contours calligraphiques.

---

## 🚀 2. Démarrage Rapide

Ouvrez simplement le fichier `index.html` dans n'importe quel navigateur, ou lancez un serveur local :

```bash
# Avec Python 3
python3 -m http.server 8080
```
👉 Accédez au studio sur : **`http://localhost:8080`**
